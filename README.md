
# 🍕 Pizza Sales Analysis Dashboard – Excel

## 📌 Project Overview
This project focuses on analyzing pizza sales data using Microsoft Excel. The goal was to explore sales performance, understand customer ordering patterns, and identify the best-selling and least-selling pizza products through an interactive dashboard.

## 🎯 Project Objectives
- Analyze overall pizza sales performance.
- Compare sales across different pizza categories and sizes.
- Identify monthly and weekly ordering trends.
- Identify the top 5 and bottom 5 pizzas based on sales.
- Present key business insights through an interactive dashboard.

## 📊 Dataset
The dataset contains pizza order information, including:
- Order ID
- Pizza ID
- Customer Name
- Quantity
- Order Time
- Order Date
- Pizza Size
- Pizza Category
- Pizza Ingredients
- Pizza Name

## 🛠️ Tools & Techniques
**Microsoft Excel**
- Data preparation and calculated columns.
- Excel formulas (Sales calculation and WEEKDAY/TEXT functions).
- PivotTables for data summarization and analysis.
- Charts and visualizations.
- Interactive dashboard with slicers and filters.

## 📈 Key Performance Indicators (KPIs)
- Total Sales
- Total Customers
- Total Orders
- Total Quantity Sold

## 📉 Dashboard Analysis
1. **Sales by Pizza Category:** Comparison of sales across different pizza categories.
2. **Sales by Pizza Size:** Analysis of sales distribution by pizza size.
3. **Monthly Orders:** Identification of monthly ordering trends.
4. **Weekly Orders:** Comparison of order volumes across weekdays.
5. **Top 5 Best-Selling Pizzas:** Ranking pizzas based on sales.
6. **Bottom 5 Least-Selling Pizzas:** Identification of pizzas with the lowest sales.

## 💡 Key Insights
- Large pizzas have the highest share of sales.
- Classic pizza is the leading category.
- Friday records the highest order volume.
- The Classic Deluxe Pizza is the best-selling product.
